## 📦 Selected Projects

### [blur-chat-extension](https://github.com/XsyCodee/blur-chat-extension)
Chrome extension that blurs chat contents on WhatsApp Web and Telegram Web.
Contact names stay readable, message previews and conversation bodies do not.
Hover to reveal. Written with CSS selectors instead of inline styles so
newly rendered messages are covered automatically.

### Network automation & monitoring
Internal tooling for ISP operations: device provisioning, PPPoE accounting,
flow telemetry, and a custom TR-069 ACS managing ONT fleets across multiple
sites. Mostly private — built for production, not for demo.

### Data center management platform
A full VMS covering rack allocation, visitor permits with QR check-in,
cross-connect records, and role-scoped access control. Laravel API,
Next.js frontend, PostgreSQL.
